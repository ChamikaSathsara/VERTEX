# VERTEX // Minimal Sharp Edge Invoice System

A high-precision, architectural invoice generator designed with **sharp edges**, **geometric typography**, **strict 0px border-radius**, **4 layout archetypes**, and **Chrome App / PWA installation support**.

---

## Quick Start

```powershell
npm start
```
Open [http://127.0.0.1:3000/](http://127.0.0.1:3000/) in Google Chrome or any browser.

---

## Key Features

1. **Dedicated Landing Showcase**:
   - High-contrast visual grid with 8 industry presets.
   - Filter by categories: `TECH`, `CREATIVE`, `CORPORATE`, `GOODS`.
   - One-click launch into the builder or start blank.

2. **4 Distinct Layout Archetypes**:
   - `SWISS MINIMAL GRID`: Classic Bauhaus hairline grid with top-right typography.
   - `MODERN HEADER BAND`: Solid accent color full-width top band with inverted text.
   - `EDITORIAL STARK LEFT`: Asymmetrical layout with a thick vertical accent spine.
   - `FRAMED LEDGER`: Double border outer frame with shaded zebra accounting rows.

3. **Template Accent Colors**:
   - Real-time color swatches (`Onyx`, `Cobalt`, `Emerald`, `Crimson`, `Amber`, `Violet`, `Slate`) + custom color picker.

4. **Enhanced UI Typography**:
   - Increased control font sizes (inputs 13.5px-14px, labels 11px-12px) with an `Aa` Normal / `AA` Large toggle in the header.
   - Bill sheet retains architectural print scale.

5. **Install as Chrome Desktop App**:
   - Full PWA support (`manifest.json` + Service Worker `sw.js`).
   - Click "INSTALL CHROME APP" in the header to run in a frameless window offline.
